# Infra Brand System

## Brand hierarchy

- **Primary brand:** Infra
- **Secondary/domain identity:** Infrastack / infrastack.app
- **Use of “stack”:** always visually subordinate. It exists to support the domain identity, not to replace the core brand name.
- **Tagline:** none.

## Visual direction

Infra should feel premium, minimal, modern, AI-native and enterprise-grade. The interface should be clean and restrained rather than overly futuristic.

The visual system is dark-first:

- Deep navy backgrounds and surfaces
- Electric blue as the primary action/accent colour
- Cyan as a secondary accent and gradient partner
- High-contrast white/light text
- Muted cool-grey supporting text

## Logo rules

- Keep the symbol geometrically simple so it survives favicons, app icons and low-resolution rendering.
- Prefer the icon-only mark at very small sizes.
- When the name is shown, make **Infra** dominant.
- If `stack` appears, keep it considerably smaller and visually quieter.
- Do not add a tagline to the logo.
- Maintain generous clear space around the mark; use at least half the icon width as breathing room where practical.
- Monochrome versions are acceptable when colour is unavailable.

## UI rules

- Use blue/cyan as accent colours, not as a full-page colour wash.
- Keep glows subtle and rare.
- Keep shadows restrained.
- Use moderate corner radii (roughly 8–12px for most controls/cards).
- Prefer crisp spacing, strong hierarchy, clean grids and simple iconography.
- Avoid bubbly consumer-SaaS styling, crypto aesthetics, gaming neon, excessive gradients or decorative glassmorphism.

## Typography

Use the existing product typeface if it is already strong and modern. If a new web/UI typeface is needed, prefer a clean sans-serif such as Geist or Inter. Avoid introducing a dependency purely for branding unless there is a clear benefit.

## Working implementation palette

These are the approved implementation values for the navy + electric blue/cyan direction:

- Navy 950: `#07111F`
- Navy 900: `#0B1627`
- Surface: `#0F1C2E`
- Raised surface: `#142239`
- Border: `#203047`
- Electric blue: `#2F80FF`
- Cyan: `#22D3EE`
- Primary text: `#F5F9FF`
- Secondary text: `#CBD5E1`
- Muted text: `#94A3B8`

Primary accent gradient: `linear-gradient(135deg, #2F80FF 0%, #22D3EE 100%)`.
